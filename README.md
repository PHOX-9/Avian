# Avian 🐦🎮  

A **Flappy Bird remake** built in **Unity**, featuring smooth controls and challenging gameplay. Guide your bird through obstacles and aim for the highest score!  

## ✨ Features  
✅ **Simple yet addictive gameplay**  
✅ **Smooth physics-based movement**  
✅ **Endless obstacle generation**  
✅ **Score tracking and game over system**  

Can you beat your high score? Play and find out! 🚀
